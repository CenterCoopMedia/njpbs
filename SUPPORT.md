# Support

For questions about the website, contact <njpbs@montclair.edu>.

For a reproducible code defect, open an issue in this repository. Include the
page or command, expected result, actual result, and a small reproduction.
For an accessibility barrier, include the affected task and input method.

Remove personal data and credentials from screenshots, logs, and examples.
Do not post account details or security-sensitive reproduction steps in a public
issue. Report security problems as described in the [security policy](SECURITY.md).
