# Security policy

Report a security vulnerability through GitHub private vulnerability reporting.
Open the repository's Security tab and select Report a vulnerability. The report
is private to the maintainers and people invited to that advisory.

Include the affected component, steps to reproduce the problem, its expected
impact, and the commit or release you tested. Use synthetic data. Exclude
passwords, access tokens, private keys, and unpublished personal information.

Keep vulnerability details out of public issues and pull requests until the
maintainers have reviewed the report and agreed on disclosure. If the private
report control is unavailable, wait for it to be enabled; do not post the report
publicly. This project does not publish a security email address.
