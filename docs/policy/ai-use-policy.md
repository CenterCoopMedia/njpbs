# AI use policy

Contributors remain responsible for code, facts, security, accessibility, and
rights in any submitted work. Review generated changes before you submit them.
Verify factual claims against a source and run the checks that prove behavior.

Do not send credentials, private records, unpublished material, or personal data
to an external tool. Use synthetic test data. Get permission before adding a new
service that processes user data or creates a recurring cost.

AI output does not replace editorial approval or permission to publish.
Maintain the same review and validation standards for all contributions.
