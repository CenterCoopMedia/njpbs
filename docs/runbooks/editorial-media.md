# Editorial media contract

Reviewed Spotlight thumbnails use the immutable media URLs in the catalog.
Each key binds SHA-256 of the publisher image URL and SHA-256 of the stored
original bytes. The public-contract fixture records those identities. Keep the
original embedded credit and usage fields unchanged. No code license grants
rights to editorial photos or remote fonts.

Before promoting a source tree that selects these objects, upload the exact
approved originals through the authorized media-storage operation. Read each
public URL back and verify length, SHA-256, MIME and embedded notices, then
verify an ordinary reader shows the intended photo. Shape-only source tests do
not prove live storage availability or rights clearance.

Perform a qualified Home refresh and inspect the selected persisted Home
sources before the switch. Every active image reference must belong to the
promoted asset/media set. Keep the previous release and assets available for
return; do not rewrite sealed snapshots or add an old-path mapping.

Browser fonts require the same public availability and MIME proof plus CORS
for public and Admin origins, CSP acceptance, and desktop/phone reader checks.
