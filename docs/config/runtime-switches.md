# Runtime switches

The [repository code owner](../../.github/CODEOWNERS) is accountable for the
switches below. The owner column identifies the responsible operational area.
When a removal condition is met, remove the switch, its obsolete branch, any
tests specific to that branch, and its supplier declarations in the same change.

The default is the behavior for an omitted setting unless a profile requires an
explicit value. **Repo** and **production Environment** identify observed
GitHub Actions settings. **Committed** identifies a checked-in profile or
build step. These are supplier values. Firestore documents, installed provider
bindings, and effective operator settings need their own readback.

The inventory for #151 excludes the separately owned Studio controls
(`LIVE_PRODUCTION_ENABLED`, `VITE_LIVE_PRODUCTION_ENABLED`, and
`LIVE_PRODUCTION_STREAM_ENABLED`), schedule controls, and the public-switch and
release-path controls in the
[CMS staging workflow](../../.github/workflows/cms-staging-deploy.yml), including
`CMS_PREVIEW_CLOUD_ENABLED`.
