# Schedule PDF fonts

Public Sans Regular, Bold and Black are unmodified static TTF files from
[USWDS Public Sans](https://github.com/uswds/public-sans/tree/e40fcf567e44b4f5f08a658247663275fa1ad741/fonts/ttf),
version 2.001 at commit e40fcf567e44b4f5f08a658247663275fa1ad741.
The original SIL Open Font License 1.1 and upstream license notices are in
OFL.txt and LICENSE.md beside the files. They are separate from the code's MIT
license. Real PDF rendering reads these committed bytes without network access.
