NJ PBS is committed to making this website usable by everyone, including people
who navigate by keyboard, use a screen reader or other assistive technology, need
captions, or rely on high-contrast or larger text.

## Conformance statement

Our goal is to conform to the Web Content Accessibility Guidelines (WCAG) 2.1,
level AA, and to apply WCAG 2.2 AA guidance where it is practical.

This is also a legal commitment. As a state agency and a state university, the
New Jersey Public Broadcasting Authority and Montclair State University are
covered by Title II of the Americans with Disabilities Act, which sets WCAG 2.1
level AA as the standard for public-entity websites by April 26, 2027. We are
building to that standard now rather than retrofitting it later.

Accessibility is checked as the site is built. Color combinations are tested
against the WCAG AA contrast minimum automatically, so a failing pairing stops a
release. The site is built and reviewed against these features:

- A "skip to content" link so keyboard users can bypass the navigation.
- A visible focus outline on every link, button, and control.
- Support for the operating system "reduce motion" setting, which turns off
  non-essential animation.
- Support for high-contrast and forced-colors display modes.
- A screen-reader cue on links that open in a new tab.
- Captions on video, text that resizes without breaking the layout, and a
  reduced-data mode for slower connections.

## Known limitations

Some features on this site open services that PBS and other partners host and
control, including the video player on watch.njpbs.org, the PBS app, account
sign-in, and the donation form. We do not control the code on those platforms, so
their accessibility is set by the partner that runs them. Where a barrier sits on
an outside service, we will raise it with that partner and point you to their
accessibility contact.

The schedule page uses a native schedule grid built in this site from
PBS-supplied listings. Its day switcher, program buttons, shortcuts, and program
details dialog are keyboard-operable, and focus returns to the program button
when the dialog closes. If the baked listings do not include the current day, the
page shows an empty current-day state with live and on-demand links instead of
presenting old listings as current. The listings data still comes from PBS, so a
PBS feed delay can leave the page temporarily without current programs.

We treat accessibility reports about this site as priority fixes. If you find a
part of the site that does not meet the standard above, tell us.

Please include the page address, the device and browser you are using, and a short
description of the barrier. We aim to acknowledge accessibility reports within five
business days and to give a target date for a fix when we respond. If the issue
involves an external PBS service, video player, donation form, or another partner
platform, we will route the report to the right contact.

## Disability-assistance contact

If you need help using this site, or want the information on a page in another
format, contact us at the email address or telephone number above and we will work
with you directly.
