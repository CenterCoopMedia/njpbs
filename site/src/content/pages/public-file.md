NJ PBS broadcasts over four transmitters licensed to the New Jersey Public
Broadcasting Authority (NJPBA). Each licensed station keeps its own FCC online
public inspection file, and FCC rules require a link to that file, plus a
station-representative contact, on the station website.

## What the public file is

The online public inspection file holds the records the FCC requires a television
station to make available to the public, including its license, ownership reports,
and equal employment opportunity filings. Each NJ PBS station's file is hosted by
the FCC at publicfiles.fcc.gov. The four files, also linked in the footer of every
page:

- <a href="https://publicfiles.fcc.gov/tv-profile/wnjs" rel="noopener" target="_blank">WNJS (Camden)<span class="sr-only"> (opens in new tab)</span></a>
- <a href="https://publicfiles.fcc.gov/tv-profile/wnjn" rel="noopener" target="_blank">WNJN (Montclair)<span class="sr-only"> (opens in new tab)</span></a>
- <a href="https://publicfiles.fcc.gov/tv-profile/wnjt" rel="noopener" target="_blank">WNJT (Trenton)<span class="sr-only"> (opens in new tab)</span></a>
- <a href="https://publicfiles.fcc.gov/tv-profile/wnjb" rel="noopener" target="_blank">WNJB (New Brunswick)<span class="sr-only"> (opens in new tab)</span></a>
