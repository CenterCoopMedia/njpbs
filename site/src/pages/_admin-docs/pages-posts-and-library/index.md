## Choose the right workspace

Start with the kind of public content you need to maintain.

| Workspace | Use it when |
| --- | --- |
| Pages | The assignment names a fixed NJ PBS page or public service route, such as About, Contact, Schedule, or another established destination. |
| Posts | The assignment is an individual editorial record that can receive its own title, route, author, dates, metadata, and workflow. |
| All content | You need to search across authorized records, combine filters, use a saved view, or reopen a result without knowing its type first. |

Do not create a post to replace an established page, and do not try to turn a
fixed page into a free-form route. The CMS keeps page identity and public paths
under system control so that one editor cannot accidentally create a competing
canonical URL.

### Identify NJ Spotlight News work

For a Post that should carry the NJ Spotlight News brand, check **Spotlight News**
in the **Metadata** sidebar. It starts unchecked. Readers see a small publication
label above the headline and on post listings; the headline and byline stay the
same. Save, check the private preview, and use the normal approval and publish
workflow. Uncheck, save, and publish to remove the label. A draft save does not
change the live story's attribution.

Posts can hold up to 200 blocks. Each Row and each block inside it counts once.
Pages keep their 40-block limit. Large text blocks can still reach the document
size limit; the save message explains what to shorten. After an update, save
your draft and reload Boardwalk to use the higher Post limit.

## Edit the Data Hub Page

Open **Pages → New Jersey by the Numbers**. Use the same Add, Outline, Arrange,
section details and Page settings as other Pages. The first opening shows the
existing Page introduction, Featured finding, finder, 18 figures and supporting
sections. Opening the Page does not save or publish a change.

Retained ordinary blocks from an older Page appear after those sections. Review
them before Preview or Publish. All retained content stays in the editor. If the
combined layout exceeds the normal 40-block limit, remove unneeded sections or
blocks before saving. Reload without saving to return to the stored Page.

The canvas shows each section's current copy and each figure's value and date.
Select a section to edit its **Heading** and **Introduction**. Placeholders show the
reviewed default until edited. Use **Reset to default** to remove an override.
Use **Page introduction** for the visible heading
and opening text. Page title and summary set browser and link metadata only.
Add ordinary text, images, cards, links or rows with **Add**. Move sections with
Arrange or the Outline controls. Hide or remove a section through its actions;
Undo restores a removal. To add it again later, choose **Data Hub section** from
Add and select the available section. Each compiled section can appear once.
An intentionally empty layout stays empty after save and reload.

Values, comparisons, source notes, dates, charts and downloads remain in the
reviewed data snapshot. Section copy does not change the figure's source data or
downloaded metadata. Check the private Preview before approval or Publish.

### Choose related reporting

Select a figure or Featured section, open its details and expand **Related
reporting**. The section selects its figure. Choose Post tags/categories or
find an NJ Spotlight News term. The preview shows up to three published matches
and the last Spotlight check. Featured can inherit Minimum wage or use its own
selection. Pin a story to keep its place, Hide to exclude it, or Show to restore
it. Unavailable pins can be removed. Finish or clear unfinished terms before Save. Before the first published mapping,
use **View current reporting** to compare the October 17 saved selection on the
[public Data Hub](https://njpbs.org/data-hub/).

Save draft and check Preview, then follow the normal approval and Publish or
Schedule workflow. Publishing a mapping enables automatic related-story updates;
empty results hide that reporting block. Until the first mapping is published,
the existing saved selection stays. Figure values, source notes and dates do not
change through this control. A source notice means the preview could not refresh
all sources; previous checked Spotlight matches remain when available.
Reporting stays attached to the figure when it moves. Removing a section keeps
its mapping for a later re-add. Page settings also provide a figure selector when
no figure section is selected, so staff can clear an unfinished term for a removed
section. Finish or clear terms before saving or leaving.

The **Pages** directory represents the fixed public route registry.

Use the row chevron to show the page details. Inside the details, open
**Quick edit and lifecycle** to change the title or description and review lifecycle
actions. Both disclosures can be opened with the keyboard. Use **Edit draft**
to open the full page editor.

1. Open **Pages**.
2. Search or scan for the assigned public page.
3. Confirm the page title and read-only public path.
4. Open the record and wait for the editor, lifecycle, and revision sections to
   finish loading.
5. Confirm whether the page already has a saved draft.
6. Review the title and summary in the main writing column, locked public
   regions, and the editable block cards. Open a card to edit it. Use Preview
   to check the public layout.
7. Make and save the assigned change.
8. Return to the directory only after the save confirmation appears.

A page can share a visual template with another page without sharing its content
record. Always use the row whose public path matches the assignment.

The Staff page is a normal Page. Edit its hero title, summary, background image
and crop, search and social fields, and any authored blocks through the usual
save, preview, and publication flow. The published roster is generated from
public author profiles and stays read-only on this Page.

### Home hero selections

Open Home. In **Page content**, select **Edit Home hero** to open the Home hero
dialog. Home requires Editor access in the Station area or a higher role with
that access. Writers cannot edit Home, including a draft they own. Select
**Done** when you finish.

When layout controls are unavailable, editing a hero saved with a lead-story
layout returns it to rotating slides and removes its lead-story headings.

Where available, use **Hero layout** to choose **Rotating hero** or **Lead story and headlines**.
The lead-story layout places the first eligible story first, followed by one,
two or three **Supporting headlines**. Remaining selected stories appear below
that group. Set **Supporting heading** and **More-stories heading** to label the
groups. This layout does not rotate. Story bylines come from the published
source; a source without an author has no byline.

Where the editorial controls are available, select a manual story and use
**Story button text** for an optional label of up to 80 plain-text characters
on one line. Leave it blank for **Read the story**, or **Watch the report** for
a PBS item, including a pasted `watch.njpbs.org` URL. The field changes the
action text and keeps its destination. Pasting a URL does not link it to a
provider catalog record.

The fallback heading, subtitle and background controls are below the slide selector. Choose **Choose slides
or paste a URL**, **Select by category**, or **Select by tags**. A selection can
show up to ten items.

- For manual slides, select a page or published Post, choose **Add from an API
  source**, or select **Add a slide with a URL**. Review the title, summary and
  destination. Select a slide in **Slides** to edit it. Use the up and down arrow
  buttons to set the order. The trash button removes the slide.
- For category selection, choose **Load available classifications**, then select
  a value. Published posts and Spotlight support categories. PBS Media Manager
  items are available through manual selection.
- For tag selection, add each tag with Enter or a comma. Match the published
  tag's exact spelling and case. Use a tag's remove control to remove it.
  New tag selections start with announcement, home, hero and main. Existing
  selections keep their saved tags until you edit them. A Post with any listed
  tag can appear, with the same order and ten-item limit.
- On a Post, select **Show in Home hero**, then save and publish the Post to
  include it without a public topic tag. This works with an existing tag-mode
  Home; Home does not need to be republished for the checkbox. Changing Home's
  tag list requires publishing Home.
- In category or tag mode, use **Pinned → Pin published content** to search
  published Posts or Pages. Select up to three. The first available pin leads;
  the remaining slots fill with the newest matching stories, without duplicates.
  Use the arrow controls to reorder pins and the remove control to unpin one.
  **Maximum stories** still limits the whole hero, including pins.
- **End time (Eastern)** is optional. Leave it blank to pin until you remove it.
  End times follow Eastern standard or daylight time, even when you travel.
  Expiry and unpinning end priority: a Post that still matches your automatic
  selection can remain in its normal date order. Unpublished, deleted or
  withdrawn content drops out. Pins follow published changes to the content.
- Save, use **Preview**, then publish Home to make pin changes public through
  the normal publishing path. No site build is needed. An ended pin loses
  priority when the next normal Home publication or source refresh finishes
  after its end time; you do not need to unpin it yourself. Reloading the public
  page alone does not publish Home. An already-open visitor page does not update
  itself. Manual slides keep their existing controls.
- The API source picker uses the catalog included with the CMS release. Select
  **Load source catalog** to inspect it. If loading fails, retry; your existing
  settings stay in the editor. A pasted URL does not import the linked page.
- Choose an optional station image with the media picker. Add an image
  description or mark it decorative. Removing an override restores provider
  artwork when available. Spotlight stories use their reviewed article photo,
  or existing Spotlight topic artwork when no article photo is available.
  Topic artwork illustrates the category; it is not a photo from the article.
  The image fills the hero background and changes with the slide's heading,
  summary and link. If no usable source or topic image exists, or the image fails
  to load, the slide uses the selected Home background or bundled fallback artwork.

An empty selection or no matching items shows the Home heading, subtitle,
selected background image and watch/donation actions. Without a selected
background, bundled blue artwork fills the hero. The site header carries the
NJ PBS logo; the hero starts with the headline and keeps its copy and actions
together without repeating the logo or adding eyebrow text.
Remove all manual slides
to use that fallback. Save and use **Preview** to check the exact draft before
publication. Later draft changes do not alter the public hero.

In **Rotating hero**, visitors can move between multiple items with Previous
and Next or pause rotation. The background and copy fade briefly between items without zooming or
moving. Keyboard focus pauses rotation. Reduced-motion settings disable
automatic rotation and make manual changes immediate. A single item stays
still; without JavaScript, the first item remains visible and linked.

### Home source shelf layouts

When layout controls are unavailable, new shelves request four items. Editing
an existing shelf returns it to a horizontal row and changes a count of three
or six to four or eight.

Where layout controls are available, open a Home source shelf and use **Shelf layout** to choose a horizontal row or
a grid. **Grid columns** sets two, three or four columns on desktop; grids use
two columns on phones. New source shelves start with a three-column grid.
Existing saved rows keep their layout until you change it. The source still
limits the item count and supplies the published cards.

Curated version 2 shelves also offer **Layout** choices **Two features** and
**List**. Two features shows two large cards per desktop row and stacks them
on phones. List shows three text columns on desktop and one list on phones,
with no images. Both keep source labels, Opinion labels, bylines and dates.
List starts at three cards unless a larger saved selection must be retained.
Use **Number of cards** to change the count within the source limit.

Open the component preview to inspect the selected layout. It loads published
source data when opened. Save and use the full-page **Preview** to check the
complete draft, including category and tag selections, before publication.

### Fixed and derived page regions

A page editor can show three kinds of material:

- **Editable content** stored in the page draft.
- **Locked context** that explains a public integration or fixed shell region.
- **Derived content** supplied by another NJ PBS or PBS data source.

Locked or derived regions are present so you can understand the complete public
page. They are not fields to reproduce as ordinary blocks.

Use **Posts** for individual editorial records.

In the article card, **Headline** and **Summary** are separate fields. Write the
short introduction in the labeled Summary field below the headline. Its empty
prompt is **Add a summary…**. The summary is optional and can also appear in
listings, search and social sharing.

To create a post:

1. Open **Posts**.
2. Select the create action.
3. Enter the required basics, including a clear working title.
4. Add the appropriate body content and metadata.
5. Save the first draft.
6. Confirm the resulting record identity and route information.
7. Continue editing only after the saved record reloads successfully.

The system owns immutable or normalized routing details. A title change can
affect a proposed slug, but the browser should not let an editor rewrite
protected identity fields arbitrarily. When a post already has a public route,
check any route-change warning before saving.

To reopen a post, use its row in **Posts**, a result in **All content**, or a
recent-work link from **Home**.

**All content** combines the records your account is authorized to see. It is
the best starting point when you know a phrase, author, status, area, or recent
action but not the exact location.

Use the toolbar to search, sort, change direction, open **Filters**, or **Save
current view**. Open **New content** to find **Post from template**. The table
header selects all eligible records on the current page; bulk actions appear
after you select a record. On narrow screens, **Last updated** appears with the
record name.

### Search

Use words that are likely to appear in the record title. Start broad, then add
filters rather than entering a long exact phrase.

When search returns nothing:

- Clear filters that may be excluding the record.
- Try a shorter title fragment.
- Confirm that you are looking for the correct content type.
- Check whether the record belongs to a area outside your access.
- Ask an administrator to verify access rather than using another account.

### Filters

Available filters can include content type, lifecycle status, assignment, area,
or other newsroom fields.

Apply one filter at a time when diagnosing an unexpected result count. Clear
filters explicitly; deleting the search text does not necessarily reset the
rest of the view.

### Personal views

Common personal shortcuts can include:

- **My recent edits**, for records you updated recently.
- **Assigned to me**, for records whose current assignment names you.
- Saved combinations of search, type, status, or other filters.

Give a saved view a name that describes the result, not the moment. “Posts
assigned to me and awaiting review” remains useful; “Editor test Thursday” does
not.

Delete temporary test views when the task is complete.

## Find a record step by step

1. Open **All content** and type a short title fragment into **Search content**.
2. Select **Filters**. Choose the content type or status you know.
3. Read the result title, type, and assignment before opening it.
4. Select the title. Keep the list's bulk-selection checkboxes clear.
5. After saving your work, use the editor's back link to return to the list.

**Check:** The same search and filters are still useful when you return. If no
record appears, remove filters one at a time and try a shorter title fragment.

## Return to the same results

When you open a record from **All content**, the CMS should preserve enough view
state to return you to the same search, filters, and page of results.

Before relying on that behavior during a large review:

1. Save the view when the filter combination matters.
2. Open one result.
3. Return using the CMS navigation or the browser's normal history action.
4. Confirm that the result set and position remain useful.
5. Reopen the saved view if the transient state was lost.

Avoid opening many editable records in separate tabs without a clear plan.
Concurrent tabs can create stale drafts, editor locks, or version conflicts.

## Read a directory row

A useful directory row normally tells you:

- Record title.
- Content type.
- Current lifecycle status.
- Last update time.
- Last editor or assignee when relevant.
- The action available to your role.

Do not infer publication from a recent update time. A newly saved draft can be
the newest record in the list while the public site still shows the prior
published version.

## Create only what the assignment requires

Before selecting a create action, confirm:

- No existing record already covers the public destination.
- The content type is correct.
- The intended author or owner is known.
- The area is correct.
- The first draft can be completed enough to identify later.
- You understand who will review and publish it.

Duplicate records make search, routing, revision history, and publication more
difficult. Search first.

## Delete cautiously

Delete and restore can have different consequences and may be restricted by role.

- **Delete** moves a page or post out of active editorial work. The confirm button says **Move to recycle bin**. The status then reads **Deleted**. The working copy, published snapshot, and revision history stay.
- **Restore to draft** returns that deleted record to draft. It does not publish it.

Staff profiles use **Archive profile**. That action is separate from deleting a page or post.

Read the confirmation, record title, and public-path consequences. Never use a
destructive action as a substitute for correcting a draft.
