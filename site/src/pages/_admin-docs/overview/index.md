## What Boardwalk is

Boardwalk is the staff workspace for maintaining the digital
content that appears on the NJ PBS website. Depending on your role, it can let
you:

- Edit fixed public pages.
- Create and maintain posts.
- Find content across the newsroom library.
- Browse and maintain station images, documents, and private staff videos.
- Listen to voiceover recordings and save personal review choices.
- Prepare bylines and staff profiles.
- Review changes and publication status.
- Inspect activity and administer staff access or global settings.

The CMS is not the public website itself. It stores editorial records and sends
approved work into a separate publication process. Some public features also
come from external services or protected integrations. The editor identifies
those regions as locked or derived instead of pretending that they are ordinary
CMS blocks.

## The draft-to-public model

Keep these stages separate:

| Stage | What it means | Public effect |
| --- | --- | --- |
| Editing in the browser | You have changed a field or block but have not saved it. | None. The work can still be lost if you leave. |
| Saved draft | The CMS has stored the current draft and added revision evidence. | None by itself. |
| Submitted or ready for review | The draft is waiting for an authorized reviewer. | None by itself. |
| Preview | The CMS has built a protected view of a specific saved draft. | None on the public site. |
| Publish or schedule | An authorized action has started the release workflow. | The public site changes only after that workflow succeeds. |
| Verified live | The released page has been checked at its public address. | The approved change is public. |

> **The central rule:** a successful draft save is not a publication. Do not
> describe content as live until the publication workflow has completed and the
> public address has been checked.

An action label can vary by content type. You may see **Save draft**,
**Submit**, **Preview**, **Publish**, or another lifecycle action. Read the
current status and the confirmation message rather than assuming that every
button performs the same kind of save.

Your rail contains only the destinations your account may use.

| Workspace | Use it for |
| --- | --- |
| Home | See recent work, current system information, and the next items that may need attention. |
| Pages | Open the fixed NJ PBS public pages and edit their saved drafts. |
| Posts | Create or maintain individual editorial records that have their own public routes. |
| All content | Search across authorized records, combine filters, use saved views, and return to prior results. |
| Media library | Choose a tab: Images, Videos, Public submissions, Audio, Favorites or Collections. Find and maintain the media available to your account. |
| Editorial queue | Review submitted content and inspect publication activity. |
| Activity | Search the administrative record of content and access changes. |
| Broadcast schedule | Read the verified internal weekly schedule for the current source packet. This does not replace the public PBS listings feed. |
| Staff profiles | Review or correct public-facing staff profile data. |
| Staff access | Review roles and area grants; high-risk role changes remain restricted. |
| Resources | Open the New Jersey politics guide. |
| Analytics | Read audience, newsletter, and website delivery reports. Managers and Site owners only. |
| Reports | File problem reports and read your own reports. Available to every staff role, including Viewer. |
| Admin settings | Maintain global newsroom settings available to Managers. |
| Around NJ | Open the Around NJ guide in a new tab. |
| Account menu | Open your profile, personal display settings, and sign-out action. |

A missing destination is not necessarily an error. The rail is
capability-aware, and a person with a narrower role should see fewer
administrative surfaces.

## A safe first session

Start with [Your first CMS session](../first-session/) for a guided practice
run with screenshots and a checklist for your trainer.

1. Open <a href="https://admin.njpbs.org/" rel="noopener noreferrer" target="_blank">Boardwalk<span class="sr-only"> (opens in new tab)</span></a>.
2. Confirm that the account name and email shown in the CMS are yours.
3. Open **Home** and read the current status before starting work.
4. Open the destination that matches the task: **Pages**, **Posts**, **All
   content**, or **Media library**.
5. Confirm the record title, public path, content type, and lifecycle status.
6. Make one small change.
7. Save it as a draft and wait for the success confirmation.
8. Reload the record and confirm that the saved value remains.
9. Use revision history or activity evidence when the task requires a review.
10. Move into preview or publication only when your role and assignment call for
    it.

## Before you edit

Confirm the following before changing a record:

- You are in the correct NJ PBS account.
- The record title and public path match the assignment.
- You understand whether the region is editable, locked, or derived.
- The latest draft has finished loading.
- Another editor does not currently hold the record.
- You know whether the task ends at a saved draft, review submission, preview,
  or publication.
- You have the original value when a reversible test or sensitive correction
  requires it.

Do not paste passwords, verification links, private member or donor
information, unpublished agreements, or other restricted material into a
content field, revision note, screenshot, or support report.

## After you finish

Before leaving the CMS:

1. Wait for the final save or lifecycle confirmation.
2. Remove any temporary marker or test content.
3. Reload when the task requires persistence evidence.
4. Check revision history when a consequential change needs an audit trail.
5. Verify the public URL only after an authorized publication has succeeded.
6. Return to **Home** or sign out when you are done.

The rest of this guide follows the same model: identify the correct surface,
make the smallest safe change, wait for explicit feedback, and verify the state
that matters.
