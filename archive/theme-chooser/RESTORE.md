# Restoring a theme experiment

The archived source uses paths relative to the website package. To evaluate a
theme, copy its components, chooser data, and assets into a temporary website
checkout. Keep the current public homepage intact until a design is approved.

Restore with current component and token tests, then run the website type check,
focused tests, build, and guardrails. Check keyboard access, reduced motion, contrast, and phone
layouts before proposing activation. Update the website documentation in the same
pull request. Deployment requires separate approval.
